Política de Privacidade — Reels Generator

Última atualização: 18 de setembro de 2026

O que é este aplicativo

Reels Generator é uma ferramenta pessoal que roda inteiramente na máquina do próprio desenvolvedor. Ela publica vídeos nos canais do YouTube que pertencem a ele e lê as estatísticas desses mesmos vídeos. Não é oferecida ao público, não tem cadastro e não possui usuários além do próprio autor.

Dados acessados

Por meio das YouTube API Services, o aplicativo acessa exclusivamente:

  • Envio de vídeos (youtube.upload) — para publicar vídeos nos canais do próprio titular da conta autorizada.
  • Leitura de dados (youtube.readonly) — para ler título, estado de publicação e estatísticas dos vídeos desses canais.

O aplicativo não acessa dados de terceiros, não lê comentários, não coleta informações de outros usuários do YouTube e não utiliza nenhum dado para publicidade, perfilamento ou treinamento de modelos.

Onde os dados ficam

As credenciais de autorização (tokens OAuth) e os metadados dos vídeos são gravados em um banco de dados local, na máquina do desenvolvedor. Nada é enviado a servidores do autor, porque não existem servidores do autor. Não há compartilhamento, venda ou transferência de dados a terceiros.

Retenção e exclusão

Os dados permanecem no banco local enquanto o aplicativo estiver em uso e são apagados junto com ele. A autorização concedida ao aplicativo pode ser revogada a qualquer momento em myaccount.google.com/permissions, o que encerra imediatamente todo o acesso.

YouTube API Services

Este aplicativo usa as YouTube API Services. Ao utilizá-lo, você está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.
